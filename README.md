# 🎮 2048 - Juego Interactivo

Un juego 2048 completamente funcional, optimizado para dispositivos móviles y desktop.

## 🚀 Características

### ✨ Jugabilidad
- **Combina fichas** iguales para crear números más grandes
- **Objetivo**: Alcanza el número **2048** 🎯
- **Sistema de puntuación** en tiempo real
- **Mejor puntuación** guardada automáticamente
- **Deshacer movimientos** (hasta 20 movimientos anteriores)

### 📱 Compatibilidad
- ✅ **100% responsive** - Funciona en cualquier tamaño de pantalla
- ✅ **Móvil optimizado** - Controles táctiles suave
- ✅ **Desktop compatible** - Controles por teclado
- ✅ **Tabletas** - Experiencia completa

### 🎯 Controles

#### En Móvil 📱
- **Desliza tu dedo** en cualquier dirección para mover las fichas
- Usa los **botones direccionales** en pantalla

#### En Desktop 🖥️
- **Teclas de flecha** (↑ ↓ ← →)
- **Teclas WASD** (W, A, S, D)
- **Botones en pantalla** ⬆️ ⬅️ ⬇️ ➡️

#### Botones de Acción
- 🔄 **Nuevo Juego** - Reinicia el juego
- ↶ **Deshacer** - Revierte tu último movimiento

## 🎨 Diseño

### Colores por Número
- **2** - Gris claro
- **4** - Crema
- **8** - Naranja claro
- **16** - Naranja
- **32** - Naranja oscuro
- **64** - Rojo naranja
- **128+** - Dorado
- **512+** - Dorado intenso
- **1024+** - Marrón oscuro
- **2048** - Amarillo con brillo ✨
- **8192+** - Negro elegante

### Animaciones
- 🌀 **Pop Animation** - Las nuevas fichas aparecen con un efecto pop
- 📈 **Merge Animation** - Las fichas se agrandan al fusionarse
- ✨ **Transiciones suaves** - Todos los movimientos son fluidos

## 💾 Almacenamiento

El juego guarda automáticamente tu **mejor puntuación** en el navegador usando localStorage.

## 🎮 Cómo Jugar

1. **Abre el juego** en tu navegador (index.html)
2. **Mueve las fichas** en cualquier dirección
3. **Combina fichas iguales** para crear números más grandes
4. **Alcanza 2048** para ganar
5. **Continúa jugando** para obtener puntuaciones más altas

### Reglas
- Cada movimiento agrega una nueva ficha (2 o 4)
- Las fichas con el mismo número se fusionan
- El juego termina cuando no hay más movimientos posibles
- ¡Intenta alcanzar la puntuación más alta posible!
